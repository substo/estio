# Studio product concept

Studio helps creators turn a source into original content they can review, edit and film. Estio and Substo share this workflow. The active Location owns its sources, knowledge, drafts and provider settings. Workspace here means the on-screen work area.

## One source, one workspace

- Open a source and work with the Assistant already on that page. The work area displays the video, transcript, knowledge, related sources, or the draft. Change modes in that workspace and keep the source and conversation available. On a smaller screen, expand the same controls within the page.
- **Create with Studio** sits in the source Assistant. The open source already supplies the subject and inspiration. Start with a useful clarification and offer selectable answers. A written brief is optional. A blank start from the Content collection can ask for a subject because no source was chosen there.
- Content is a way to find and resume saved work. A source-linked creation returns to that source workspace and its saved draft. Opening knowledge or comparing ideas during creation keeps the user in the workspace.
- Keep the controls for the current mode visible. Use expandable panels for evidence, settings, and run details. Preserve current work when switching modes. Ask the product owner before implementing a new route or a different interaction if this direction leaves a material ambiguity.

## How the Assistant should work

1. **Research.** Use the current source, its transcript and available slide evidence. Let people inspect and approve cited findings or discuss them with the Assistant. Offer an evidence review in place. Show gaps in the evidence.
2. **Clarify.** Ask only questions that change the work. Establish who publishes, who should watch, and what the video should accomplish. Treat an example or case study as a separate creative choice. Offer short choices and an optional typed or dictated answer.
3. **Suggest.** Use eligible source evidence to propose distinct original concepts. Keep source ideas as inspiration and attribute claims. A user can accept, shortlist, skip, or request a different direction before moving on.
4. **Develop.** Work through Concept, Angle, Title, Hook, Payoff, Script and Shoot plan as stages of one draft. The active stage has its own suggestions and controls. Carry accepted decisions forward. Show how the title’s promise will appear in the opening and pay off by the end.
5. **Edit and approve.** Support direct edits, selection-level literal replacement, AI rewrite preview, comments, dictation and undo where applicable. Keep proposals separate from accepted text. Ask for approval before canonicalizing the script or producing an external effect.

## Context and authority

- Build each run from the active stage, confirmed direction, accepted earlier decisions, authorized current evidence, and explicit feedback. Use the Business profile for the publisher’s voice and the pinned template for structure. A brand profile or source may suggest an idea. It cannot silently decide the audience or publisher.
- Keep the conversation visible when switching modes. A message becomes generation input when the workflow explicitly carries it into the next run. Saved source notes and historic drafts stay out by default. A specific historic draft can be included for a chosen comparison or revision.
- Show **Context for next run** for editable choices and **Inputs used by this run** for the immutable snapshot. Explain decisions with a short rationale and traceable evidence. Retain prior review provenance when a connection is removed.
- Follow [AI workflows](ai-workflows.md) for user and Location authority, Mac availability, provider choice, explicit paid authorization, and uncertain job recovery.

## What to check before shipping

Start from an actual Library source. Click Create in the Assistant, answer the direction question without writing a brief, and request original ideas. Verify the source URL stays in place, the AI receives the source evidence, and switching back to Knowledge preserves the draft and conversation. Continue through title, hook, script and shoot plan on that page. Reload a saved draft and verify its context and proposals. Check desktop, keyboard and touch layouts, an unavailable provider, and a source without usable evidence.

For the MrBeast reference, a test direction is Substo publishing for first-time creators. Suggest ideas that teach the source topic through a creator’s own video, such as comparing two openings and showing which promise each makes. A customer’s promotional video would require an explicit change of publisher, audience and goal.

## Follow-on workflow

Related research and optional audience-comment insights fit in the same workspace. Treat comments as attributed audience language, questions and reactions. Keep that context separate from verified factual evidence and bring it into generation deliberately. Add more contextual follow-up questions and per-finding selection using existing review and job controls as the workflow needs them.
