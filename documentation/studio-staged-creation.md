## Drafts and editing

Use the seven stage buttons to switch the active editor. **Approve for use** marks text as an accepted input. **Shortlist** saves an alternative. Select an exact passage with touch or the keyboard and open **Selection actions**. Exact replacement runs inside Studio without generation. **Shorten**, **Simplify**, and **Rewrite** queue a proposal for the captured span. Apply checks the current record version, stage and selection. Undo restores the previous saved value for that stage. Comments can attach to the stage or the selected words. Dictation uses the browser speech service where available, with a typed field and device keyboard fallback.

Full-script generation pins the confirmed direction, supplied brief, earlier accepted stages, bounded Business profile context, current linked evidence, and an optional approved template version. Eligible current approved extraction quotes take priority. Saved transcript excerpts fill gaps. The reviewer sees the proposal and its immutable **Inputs used by this run** disclosure, including the exact structured data passed to the provider. It shows the supplied instructions, cited passages, Business fields, template and content versions, and omissions or truncation. **Context for next run** controls linked reference evidence and optional use of one linked saved script for comparison or revision. Historic drafts and all saved record notes are off by default. Managing links or archiving a record leaves completed proposal snapshots intact. Applying a reviewed draft is separate from generation. Prior model drafts remain in decision history, and applying a draft retains the previous script for Undo. Existing legacy drafts retain their own review and application path.

Staged generation uses the canonical `script_brief` queue and `studio.creation.v1` snapshot mode. Both providers retain existing Location and account admission, consent, leases and meter semantics. The paired Mac must advertise `stagedCreationVersion: 1`. The old script brief path and recurring v2 prompt remain available. Roll out the new migration and updated hosted worker and companion through the canonical release workflow.
